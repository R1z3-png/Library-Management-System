# Library Management System

Консольное приложение для управления библиотекой. Программа позволяет добавлять и удалять книги, регистрировать пользователей, выдавать и возвращать книги, искать книги, отслеживать просрочки и просматривать историю заимствований.

## Возможности

- добавление книг в каталог;
- удаление доступных книг;
- поиск по названию, автору или ISBN;
- добавление пользователей трёх типов;
- выдача и возврат книг;
- проверка лимита книг для пользователя;
- расчёт срока возврата;
- просмотр просроченных книг;
- просмотр каталога, пользователей и истории заимствований.

## Правила выдачи

| Тип пользователя | Максимум книг | Срок выдачи |
|---|---:|---:|
| Student | 3 | 14 дней |
| Faculty | 10 | 30 дней |
| Guest | 1 | 7 дней |

Книгу нельзя выдать, если она уже выдана. Пользователь не может превысить свой лимит. Удалить можно только доступную книгу.

## Структура проекта

```text

├── main.py         # консольное меню и точка входа
```

## Требования

- Python 3.8 или новее;
- дополнительные библиотеки не требуются — приложение использует стандартную библиотеку Python.

Данные хранятся в памяти и не сохраняются после завершения программы.

## Запуск

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/R1z3-png/SQL_project.git
cd SQL_project
```

Запустите приложение:

```bash
python main.py
```

Если в системе команда `python` указывает на другую версию Python, используйте:

```bash
python3 main.py
```

## Работа с меню

После запуска доступны следующие пункты:

1. Добавить книгу.
2. Удалить книгу.
3. Найти книгу по названию, автору или ISBN.
4. Добавить пользователя.
5. Выдать книгу.
6. Вернуть книгу.
7. Показать просроченные книги.
8. Показать все книги.
9. Показать всех пользователей.
10. Показать историю заимствований.
0. Выйти из программы.

### Пример сценария

1. Добавьте книгу: укажите ISBN, название и автора.
2. Добавьте пользователя: выберите тип, затем укажите ID и имя.
3. Выдайте книгу, введя её ISBN и ID пользователя.
4. Программа покажет дату, до которой книгу нужно вернуть.
5. После возврата запись останется в истории заимствований.

## Архитектура

### `Book`

Хранит ISBN, название, автора и статус доступности книги. Методы `mark_borrowed()` и `mark_returned()` изменяют статус книги.

### `User`

Хранит ID, имя и список ISBN книг, находящихся у пользователя. Метод `can_borrow()` проверяет, не достигнут ли лимит.

Классы `Student`, `Faculty` и `Guest` задают собственные значения `MAX_BOOKS` и `LOAN_DAYS`.

### `Library`

Управляет словарями книг и пользователей, а также списком записей выдачи. Основные методы:

- `add_book()` и `remove_book()`;
- `search_books()`;
- `add_user()` и `find_user()`;
- `borrow_book()` и `return_book()`;
- `get_overdue_records()`;
- `get_borrow_history()`.

### `BorrowRecord`

Содержит ISBN книги, ID пользователя, дату выдачи, срок возврата и дату фактического возврата. Запись позволяет определить, является ли выдача активной или просроченной.

## Обработка ошибок

Приложение использует собственные исключения, унаследованные от `LibraryError`, например:

- `BookNotFoundError` — книга не найдена;
- `BookNotAvailableError` — книга уже выдана;
- `UserNotFoundError` — пользователь не найден;
- `BorrowLimitExceededError` — достигнут лимит книг;
- `BookNotBorrowedByUserError` — книга не числится за пользователем.

Ошибки операций в консольном меню перехватываются и выводятся пользователю без завершения программы.

## Ограничения

- данные не сохраняются между запусками;
- отсутствуют графический интерфейс и веб-интерфейс;
- приложение рассчитано на работу одного пользователя через консоль;
- база данных не используется, несмотря на имя репозитория `SQL_project`.
