# Library Management System

Консольное приложение для управления библиотекой. Программа позволяет добавлять и удалять книги, регистрировать пользователей, выдавать и возвращать книги, искать книги, отслеживать просрочки и просматривать историю заимствований.

## Возможности

- добавление книг в каталог;
- удаление доступных книг;
- поиск по названию, автору или ISBN;
- добавление пользователей трёх типов;
- выдача и возврат книг;
- проверка лимита книг для пользователя;
- расчёт срока возврата;
- просмотр просроченных книг;
- просмотр каталога, пользователей и истории заимствований.

## Правила выдачи

| Тип пользователя | Максимум книг | Срок выдачи |
|---|---:|---:|
| Student | 3 | 14 дней |
| Faculty | 10 | 30 дней |
| Guest | 1 | 7 дней |

Книгу нельзя выдать, если она уже выдана. Пользователь не может превысить свой лимит. Удалить можно только доступную книгу.

## Структура проекта

```text
.
├── main.py         # консольное меню и точка входа
├── library.py      # каталог, пользователи и операции выдачи
├── book.py         # модель книги
├── user.py         # User, Student, Faculty и Guest
└── exceptions.py   # пользовательские исключения
```

## Запуск

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/R1z3-png/SQL_project.git
cd SQL_project
```

Запустите приложение:

```bash
python main.py
```

## Работа с меню

После запуска доступны следующие пункты:

1. Добавить книгу.
2. Удалить книгу.
3. Найти книгу по названию, автору или ISBN.
4. Добавить пользователя.
5. Выдать книгу.
6. Вернуть книгу.
7. Показать просроченные книги.
8. Показать все книги.
9. Показать всех пользователей.
10. Показать историю заимствований.
0. Выйти из программы.

## Ограничения

- данные не сохраняются между запусками;
- отсутствует графический интерфейс;
- приложение рассчитано на работу одного пользователя через консоль;
